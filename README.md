AI-Powered Class Schedule & Reminder Automation

Project Overview

This is a personal productivity automation project built to solve a real-life problem: forgetting upcoming classes and having to constantly check my calendar.

As part of my AI and Automation learning journey, I decided to apply what I was learning to make my daily schedule easier to manage.

The Problem

I had multiple classes and other responsibilities to keep track of. I needed a reliable way to organise my upcoming classes and receive reminders without constantly checking my calendar.

The Solution

I used ChatGPT to help organise and create my upcoming class events in Google Calendar.

Each class was configured with a reminder 30 minutes before the scheduled start time.

Tools Used

* ChatGPT – AI assistance and event organisation.
* Google Calendar – Class scheduling and reminder management.
* iPhone Notifications – Receiving reminder alerts.

Workflow Architecture

ChatGPT → Google Calendar → Scheduled Class Events → 30-Minute Reminders → iPhone Notifications

Project Outcome

* 24 upcoming class sessions organised.
* Automatic reminders configured for each class.
* Reduced the need to manually check my timetable.
* Improved personal organisation and time management.

What I Learned

AI and automation are not only for CEOs, large companies, or business owners.

They can also solve everyday problems, reduce mental workload, and make personal life more organised.

This project is part of my journey into AI and Automation.

I’m learning by building, experimenting, and solving real problems.
